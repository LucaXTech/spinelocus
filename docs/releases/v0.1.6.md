## Overview

**SpineLocus v0.1.6** is the first public research-software release for localizing vertebral landmarks (T1–T11) in **Digitally Reconstructed Radiographs (DRRs)**. It combines global **YOLO-Pose** predictions with optional local **HRNet** heatmap-based refinement.

The repository includes a reproducible Python implementation, configuration examples, patient-level split audits, evaluation tools and synthetic tests. **Research use only; not validated for clinical use.**

## Key features

- Global detection of 11 thoracic landmarks with YOLO-Pose.
- HRNet crop-based refinement, including two-model coordinate ensembles and HRNet test-time augmentation.
- Optional anatomical identity consistency guard and identity-shift diagnostics.
- Experimental horizontal-flip YOLO aggregation before crop formation.
- Subject-disjoint train/validation/test splitting and dataset integrity checks.
- PCK, Euclidean localization error, error percentiles and paired patient-level bootstrap analyses.
- Reproducible evaluation, prediction replay and visualization tools.
- Python command-line workflows for Windows and Linux.

## Development validation

The fixed baseline was assessed on a **repeatedly inspected validation set of 750 images from 15 subjects**. These are descriptive development-validation results, not an independent estimate of performance on unseen subjects.

| Metric | Primary pipeline: YOLO960 + HRNet ensemble, no YOLO flip |
| --- | ---: |
| Patient-averaged PCK@5 px | **82.31%** |
| Mean Euclidean localization error | **6.424 px** |
| 95th-percentile localization error | **36.452 px** |
| Missing predictions | **0** |

The exploratory two-view YOLO flip variant achieved **82.86%** patient-averaged PCK@5, **6.126 px** mean error and **34.201 px** P95. The paired patient-bootstrap 95% confidence interval for its PCK@5 gain was **−0.29 to +1.23 percentage points**, and for mean-error reduction **−0.045 to +0.553 px**. Both include zero. Consequently, **the no-flip method remains the primary validation baseline**. No held-out final-test result is claimed.
